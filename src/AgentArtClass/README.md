# AgentArtClass — Multi-Agent 2D/3D Asset Generation Architecture (Google Imagen + Meshy.ai)

## 1. Overview & Purpose

`AgentArtClass` is the self-contained multi-agent asset generation subsystem for **The House**. It decouples 2D concept/texture synthesis (**Google Imagen** via `@google/genai`) and 3D mesh generation (**Meshy.ai Text-to-3D / Image-to-3D API** + procedural composite fallback) from the core simulation loop.

Every item generated by `AgentArtClass` is automatically bound with **Smart Object Advertisements** (deterministic 1–10 motive deltas and environmental aura scores) so autonomous characters immediately recognize, evaluate, and interact with new furnishings, wallpapers, and carpets.

---

## 2. Multi-Agent Pipeline Architecture

```
User / Builder Agent Prompt
        │
        ▼
┌──────────────────────────────────────────────────────────┐
│ AGENT 1: Visual Concept & Surface Texture Agent (Imagen) │
│ • Synthesizes orthographic 2D concept renders            │
│ • Generates seamless PBR textures for Wallpapers/Carpets │
└──────────────────────────┬───────────────────────────────┘
                           │ 2D Reference Image + Prompt
                           ▼
┌──────────────────────────────────────────────────────────┐
│ AGENT 2: 3D Mesh Sculptor Agent (Meshy.ai + Three.js)    │
│ • Dispatches Image-to-3D / Text-to-3D job to Meshy.ai    │
│ • Normalizes bounding box & bottom-center ground pivot   │
│ • Provides zero-latency 3–12 part procedural fallback    │
└──────────────────────────┬───────────────────────────────┘
                           │ Normalized 3D Object3D + GLB
                           ▼
┌──────────────────────────────────────────────────────────┐
│ AGENT 3: Smart Object Mechanics & Aura Calibrator        │
│ • Computes 1–10 motive deltas (+-) & Environmental Score │
│ • Assigns Trait Affinities (Creative, Neat, Bookworm...) │
│ • Registers item into the 64x64 Lot Grid & Room Catalog  │
└──────────────────────────────────────────────────────────┘
```

## 3. Agent 1: Google Imagen 2D Concept & Texture Specification

### 3.1 Model & Endpoint Configuration
- **Model**: `gemini-3.1-flash-lite-image` (or `gemini-nano-banana-2.1` for 2K/4K studio textures)
- **Server Proxy Route**: `POST /api/agent-art/imagen`
- **Prompt Template for 3D Reference Concepts**:
  ```text
  Orthographic 3/4 isometric studio product render of a {styleTheme} {itemName} crafted from {materialFinish}, isolated on a pure neutral #f5f5f4 background, crisp architectural silhouette, stylized PBR materials, no text, no watermark, game asset reference sheet.
  ```
- **Prompt Template for Seamless Wallpapers & Carpets**:
  ```text
  Seamless tileable architectural texture of {patternName}, {materialFinish} surface finish, flat orthographic top-down view, uniform studio lighting, PBR albedo map.
  ```

## 4. Agent 2: Meshy.ai 3D Asset Generation Specification

### 4.1 Meshy.ai REST API Workflow

1. **Text-to-3D Preview Task**:
   - **Endpoint**: `POST https://api.meshy.ai/openapi/v2/text-to-3d`
   - **Headers**:
     - `Authorization: Bearer ${process.env.MESHY_API_KEY}`
     - `Content-Type: application/json`
   - **Payload**:
     ```json
     {
       "mode": "preview",
       "prompt": "Stylized Sims-like architectural furniture: Vintage Espresso Machine, brushed steel and walnut wood, clean topology",
       "art_style": "realistic",
       "should_remesh": true,
       "target_polycount": 5000,
       "topology": "quad"
     }
     ```
2. **Text-to-3D Refine Task** (triggered once preview status === `SUCCEEDED`):
   - **Payload**:
     ```json
     {
       "mode": "refine",
       "preview_task_id": "<task_id>",
       "enable_pbr": true
     }
     ```
3. **Image-to-3D Task** (using Agent 1's Imagen output):
   - **Endpoint**: `POST https://api.meshy.ai/openapi/v1/image-to-3d`
   - **Payload**:
     ```json
     {
       "image_url": "data:image/png;base64,<imagen_base64>",
       "enable_pbr": true,
       "should_remesh": true,
       "target_polycount": 6000
     }
     ```
4. **Polling & Asset Normalization**:
   - Poll `GET https://api.meshy.ai/openapi/v2/text-to-3d/:taskId` until `status === "SUCCEEDED"`.
   - Load `model_urls.glb` via Three.js `GLTFLoader`.
   - **Mandatory Normalization**:
     - Compute `THREE.Box3().setFromObject(gltf.scene)`.
     - Scale uniformly so max dimension fits the target footprint (`1.0m – 2.4m`).
     - Shift geometry so `box.min.y === 0` (bottom-center pivot flush with the floor at `y = 0`).
     - Enable `castShadow = true` and `receiveShadow = true` on all child meshes.

## 5. Agent 3: Smart Object Advertisement & Environmental Influence Specification

Every generated asset includes deterministic **1–10 ratings** that shape autonomous agent behavior:

| Parameter | Range | Behavioral Effect on Surrounding Toons |
| :--- | :--- | :--- |
| `environmentScore` | `1 – 10` | High aesthetic surroundings (`>= 7`) boost `sanity` (+0.5/hr) and `fun` (+0.4/hr); low or broken surroundings (`<= 3`) agitate `Neat` and `Snob` toons. |
| `comfortRating` | `1 – 10` | Scales `energy` recovery speed on seating and beds. |
| `intellectualAura` | `1 – 10` | Attracts `Bookworm`, `Genius`, and `Creative` toons to study, paint, or read the newspaper nearby. |
| `socialGravity` | `1 – 10` | Pulls multiple toons into shared rooms (Living Room, Kitchen Dining, Patio) for spontaneous conversations. |

## 6. How to Add New Items to the Catalog

1. Define an `AgentArtItemSpec` in `AgentArtPipeline.ts` or via the in-game **Build & Home Creation Studio**.
2. Call `AgentArtClass.synthesizeSmartObject(spec)` to generate the calibrated `SmartObject` with its 1–10 motive advertisements and 3D procedural/Meshy representation.
3. For Wallpapers and Carpets, register a `RoomSurfaceStyle` preset in `WALLPAPER_CATALOG` or `CARPET_CATALOG` and apply it per-room or house-wide.
